# PipelineCraft (working name)

_2026-10-15 · spec draft v0 · status: no code yet; spec lives in `docs/spec/`_

- **Scope:** the local hub that discovers, calls, chains and observes the Crafting apps on Paul's
  machine, and exposes the suite as one MCP server. Separate from the Storyteller web API.
- **Project goal it serves:** local-first Crafting apps that hand work to each other
  (AssetCraft → StoryCraft → FilmCraft, later PrepressCraft) without the cloud.
- **Immediate area of improvement:** decide the five "★ decide first" items in
  `docs/spec/15-decisions.md`, then the integration pass merges the sections into one spec.
